# Журнал сделок trade-ai-analyst
Записывать только по просьбе пользователя (решение пользователя). Пишет `journal.py` (add, close, cancel, stats).
Где лежит: папка `TRADE_ANALYST_HOME` (по умолчанию `~/trade-ai-analyst`), файл `journal/journal.jsonl` — вне плагина,
обновление плагина его не трогает. Эта папка в проекте хранит только описание схемы.
Формат: одна сделка на строку (JSON). Файл неверного формата даёт условию «лимиты счёта» статус unknown и не блокирует статус стратегии.

| Поле | Значение |
|---|---|
| id | уникальный идентификатор сделки |
| symbol | тикер, например BTCUSDT |
| strategy | название стратегии |
| side | long или short |
| kind | коррекция или продолжение |
| sweep | был или не был |
| date_open | дата открытия, YYYY-MM-DD (UTC) |
| date_close | дата закрытия, YYYY-MM-DD (UTC) или null |
| entry | цена входа |
| stop | цена стопа |
| target | цена цели |
| rr_planned | плановый R:R |
| risk_pct | риск в % |
| flags | список флагов |
| status | open, closed или cancelled |
| result_r | результат в R после комиссий или null |
| pnl_pct | результат в % счёта (result_r × risk_pct) или null |
| notes | заметки |
| rules_verdict | что сказали правила на момент входа: ВХОД ДА, ЖДАТЬ или НЕТ |
| taken | true — сделка взята, false — только записана для сравнения |
| tags | необязательные теги, список |
| entry_type | лимит или рынок (для комиссий) |

Комиссии в result_r: вход лимитом maker 0.02%, по рынку taker 0.055%; выход по цели maker 0.02%, по стопу taker 0.055% плюс проскальзывание 0.02%, иначе taker 0.055%.
Лимиты считаются так: открытый риск = сумма risk_pct у open; убыток за день и неделю = сумма pnl_pct у closed по date_close.
`journal.py stats`: по стратегии, тегам, флагам и по паре «вердикт правил × взял/не брал», с ДИ95 и пометкой «мало данных» при выборке меньше 30.
